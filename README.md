# Semana-4-Actividad-3-Aplicaci-n-de-T-cnicas-de-Optimizaci-n-en-una-Red-Neuronal-en-Google-Colab-
Objetivo: Evaluar el impacto de la tasa de aprendizaje en el proceso de optimización de una red neuronal.
Implementación: Comparativa de dos configuraciones de entrenamiento (Learning Rate 0.1 vs 0.8) manteniendo arquitectura y datos constantes.
Resultados: Se evidenció mediante gráficos de convergencia que una tasa de aprendizaje más alta acelera la reducción del loss sin comprometer la estabilidad en el problema XOR.
Métrica: Evaluación mediante Error Cuadrático Medio (MSE), demostrando un ajuste superior en la configuración de 0.8.
